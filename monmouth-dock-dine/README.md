# Monmouth Dock & Dine

A boater-first, county-wide dock-and-dine guide for Monmouth County, New Jersey.

## Coverage

- Raritan Bay / Keyport
- Atlantic Highlands / Sandy Hook Bay
- Highlands / Shrewsbury River mouth
- Sea Bright / Shrewsbury River
- Monmouth Beach / Channel Club
- Oceanport Creek
- Navesink River / Red Bank / Rumson
- Shark River / Neptune City / Belmar
- Manasquan River / Brielle

The site separates direct restaurant docks from marina-access restaurants and call-first/provisional locations.

## Live behavior

The static HTML page calls NOAA Tides & Currents directly in the browser. It uses local prediction stations near each waterway and, when a credible marina/dock depth at MLLW or MLW is published, estimates water depth at the present tide. The user can enter boat draft and desired under-keel clearance.

The map uses OpenStreetMap as the base and OpenSeaMap as a seamark overlay. Dashed approach lines are orientation only; they are deliberately not navigational routes.

## Navigation disclaimer

This is a planning aid, not a navigation product. Use current NOAA ENC, Coast Pilot, USCG Local Notice to Mariners, active aids to navigation, bridge status, marina instructions and the vessel's depth sounder. Marina depths and transient policies can change quickly due to shoaling, storms, dredging and operations.
